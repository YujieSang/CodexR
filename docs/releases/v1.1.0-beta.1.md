# CodexR v1.1.0-beta.1

The first downloadable preview of CodexR: an unofficial Android client for using Codex with a controlled root shell.

## Highlights

- ChatGPT OAuth and OpenAI Platform API-key authentication, with encrypted credential storage.
- Live model discovery, reasoning-effort controls, persistent chat sessions, usage checks, and system/light/dark themes.
- Markdown rendering with headings, lists, tables, code blocks, and offline inline/display LaTeX.
- Selectable response text and a button to copy the original Markdown.
- Long-press editing of user messages, Stop during processing, and Retry after errors or interruptions.
- Follow-ups queued while the model or a command is working, then delivered after the next tool result.
- Background execution with a work notification, notification Stop action, and screen-awake behavior during active turns.
- Images, UTF-8 text/code files, and PDFs as attachments. PDFs are rendered into page images for both authentication paths.
- An AI-callable `capture_screen` tool that returns an image to the model, plus manual capture with a countdown and draft preview.
- Per-command root approval, revocable permission for the current chat, and optional persistent full-access mode.
- Reliable stdout, stderr, and exit-code capture, with process-group cancellation for active commands.

## Download and install

Download **CodexR-v1.1.0-beta.1.apk** from the release assets. Android 7.0+ and a working root implementation with `su` and `setsid -w` are required for root tools. Authenticate with a ChatGPT account that has Codex access or an OpenAI Platform API key.

With ADB:

```bash
adb install -r CodexR-v1.1.0-beta.1.apk
```

This is a **non-debuggable preview signed with the maintainer's existing development certificate**. It can update previous installed builds signed with that certificate. Other locally built copies may have a different certificate and cannot be updated in place. Do not uninstall to resolve that mismatch without a data-migration plan: uninstalling deletes local chats, attachments, and sign-in. No private signing key is shipped with the release. A dedicated production-signing setup is still pending.

`SHA256SUMS.txt` contains the APK checksum. The app package remains `com.example.codexmobile`; this release uses version code **2**.

## Background setup

Allow notification permission. For reliable long screen-off sessions, open **Background execution / battery settings** in the sidebar and choose **Unrestricted** / **Don't optimize** for CodexR. Vendor battery policies and Android foreground-service limits still apply. Force-stopping the app ends its session; interrupted root work is not silently restarted.

## Safety and limitations

- Root commands can damage the device or erase data. Approval-required mode is recommended.
- “Allow for this chat” covers subsequent commands and AI screen captures in that chat, and resets when the app process restarts. Full access persists until disabled.
- Stop cannot undo completed changes; processes that deliberately detach into a new session can escape process-group cancellation.
- Screenshots can include private information. Protected windows may be blank; capture does not unlock the device.
- Attachment limits: 10 MB per import, 256 KB per UTF-8 text/code file, eight prepared attachments/PDF pages per message, and 24 MB of prepared attachments per conversation. Other binary formats are not supported.
- ChatGPT backend behavior can change. API-key billing and usage remain separate from ChatGPT subscription usage.
- The app is unofficial and experimental, not an OpenAI product.

## Verification

The feature update passed 25 local tests and three targeted rooted-device tests on a Lenovo TB-J716F running Android 16. Live checks confirmed AI screen capture, rendered Markdown and LaTeX, text selection, completion in the background, and a queued follow-up delivered after command output while the screen was off. Other root managers and devices have not all been validated.
